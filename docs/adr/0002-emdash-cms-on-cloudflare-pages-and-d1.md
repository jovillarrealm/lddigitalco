# Adopción de Astro y EmDash CMS sobre Cloudflare Pages y D1

Para construir un LMS ágil y moderno sin incurrir en costes fijos de servidores (como VPS tradicionales o hosting PHP para Moodle/WordPress), decidimos utilizar Astro integrado con EmDash CMS (y su plugin EmDash Learn), desplegado en Cloudflare Pages con base de datos Cloudflare D1 en el Edge. Esta arquitectura garantiza alojamiento gratuito dentro de los límites de Cloudflare (Pages y D1), seguridad aislada para extensiones y compatibilidad nativa con agentes de IA mediante el protocolo MCP.
